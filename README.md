macOS 菜单栏硬件监控。实时看 CPU、内存、磁盘、网络、电池、亮度、进程占用，带趋势图和阈值告警，还有一个能拖来拖去的悬浮小窗。纯 SwiftUI 写的，数据全是系统接口直接读，没有第三方依赖，跑起来内存占用很低。

## 能看什么

- CPU 占用率，内存占用和组成（应用/联动/压缩/空闲），磁盘剩余
- 电池电量、健康度、循环次数、充电状态、电池温度
- 屏幕亮度
- 网络上下行速率
- 进程 CPU/内存 TOP 10，横向条形图，名称完整显示
- 温度、CPU、内存、网络的历史曲线（Swift Charts）
- 阈值告警：超了就发系统通知、提示音，菜单栏图标变红
- 主界面分成四个标签页：监控、剪贴板历史、工具箱（系统信息、二维码、单位换算、文本统计、编码、颜色、便签、常用文件夹、高级功能）、专注（番茄钟 / 精确时钟 / 噪音检测）

深浅色自适应，悬浮窗和主界面平时都隐藏，不占屏幕。

## 专注模式（1.0.7 新增）

番茄钟不只是个倒计时，可以当专注软件用：

- **沉浸全屏**：一键进入全屏专注视图，只剩超大倒计时和进度环，Esc 退出
- **精确时钟**：计时用单调时钟锚点法（`CACurrentMediaTime`），不靠 Timer 累减，睡眠唤醒、系统时间跳变后自动重校准；界面同时显示毫秒级系统时间与校准偏差
- **麦克风噪音检测**：实时分贝 + 噪音等级（安静 / 适中 / 吵闹 / 太吵）+ 波形，觉得吵可以调环境；**可随时关闭，关闭后完全不占用麦克风**，系统指示灯会熄灭
- **结束提示音**：内置 13 种系统音效，也可以选自己的音频文件（mp3 / wav / m4a / aiff / caf，自动复制到应用支持目录），音量单独可调，支持试听
- **番茄节奏**：自定义专注时长、短休 / 长休分钟数、每几轮长休、自动开始下一轮；按天统计完成番茄数与累计专注时长
- **专注音景**：雨声 / 海浪 / 风扇三种环境声，用 AVAudioEngine 本地合成（不含任何音频素材、不联网、不录音），音量独立可调
- **专注统计**：近 7 天柱状图、连续专注天数、今日番茄数与累计时长
- **新手引导**：首次启动自动播放漫游式教程，17 步逐个功能介绍，切页后气泡平滑跟位，结束自动回到监控主界面；设置里可重新播放

## 性能优化（2.1.6）

针对主窗口卡顿，逐项削掉常驻开销：

- **卡面流光**：原来每张玻璃卡片各跑一个 20fps `TimelineView`，每帧重绘 Canvas 渐变与描边再叠 4pt 模糊，十张卡片约 200 次重绘/秒。改成一条普通 `LinearGradient` 用 `offset` + `repeatForever` 做图层动画，只改 transform，由 CoreAnimation 合成，不重算视图、不重绘画布、不用模糊
- **采样历史**：`history` 从 `@Published` 改为普通数组。之前每秒 append 会广播给所有订阅视图、触发整棵视图树重算；图表仍读 5 秒同步的 `chartHistory`，UI 条数改用 5 秒同步的 `historyCount`，CSV 导出直接读数组
- **Dock 角标**：缓存上次字符串，温度整数没变就不写 `dockTile`，不再每秒重绘 Dock
- **共享快照**：widget 用的 JSON 编码 + UserDefaults 写盘从每秒降到 5 秒一次
- **其它计时器**：全屏专注呼吸背景 20fps → 12fps；压力测试页 5 个 `TimelineView`（最高 60fps）统一 24fps
- 系统「减少动态效果」或关掉设置里的液态玻璃开关时，卡面流光完全静态

## 原生按钮与列表栏（2.1.5）

修掉 2.1.4 侧边栏的错位问题，按 macOS 原生外观重做：

- **原生按钮**：标题栏左侧加系统 `.bordered` 按钮（SF Symbol `sidebar.left`），点击展开／收起侧边栏；顶部「立即刷新」等保持 `.bordered`
- **原生列表栏**：`List` + `.listStyle(.sidebar)`，选中高亮完全交给系统画（系统强调色、系统圆角），不再自己叠蓝色胶囊
- **对齐**：每行固定 22pt 图标槽、统一 13pt 字号、统一 28pt 行高与 `listRowInsets`；`wrench.and.screwdriver` 这类复杂符号不会再撑大、文字左边缘四行严格一致
- **液态光晕**：删掉独立全局 Canvas 层（它用自定义坐标空间猜行位置，正是「褐色椭圆横在两行之间」的原因）。现在光晕挂在选中行自己的背景上，只在这一行内部形变，永远不会盖到别的行；透明度 0.13，系统蓝色高亮为主视觉
- 跨多行切换仍会短暂拉长、留一枚缩小的液滴和两枚小气泡，用 `Shape.animatableData` + `withAnimation(.spring)` 逐帧插值；系统「减少动态效果」或关掉设置里的液态玻璃开关时静态

## 温度是怎么读的

温度这块单独说。Apple Silicon 上芯片温度不在 SMC 里，而是挂在 HID 传感器集线器（IOHIDEventSystemClient，usagePage 0xFF00）上。本机实测能读到 45 个传感器：PMU tdie/tdev、NAND、电池、tcal 这些，芯片温度取全部 tdie 读数的最大值。这个路径普通权限就能读，不需要 root。

这接口是私有 API，Swift 头文件里没有，所以是 dlopen + dlsym 动态调出来的。

## 风扇为什么显示 --

M 系列上风扇转速只有 SMC 的 F*Ac 这类 key 有，而新版 macOS 的 AppleSMCKeysEndpoint 对普通进程直接拒绝，所有参数组合都试过，一律 kIOReturnBadArgument。BuhoCleaner 能显示风扇，是因为它内置了一个需要开发者证书签名的 root 特权助手，普通 App 装不了这个东西。所以风扇显示 --。SMC 协议代码是完整写好的，等系统接口放开，或者换正式版系统，就能自动恢复显示。

## 构建

Xcode 直接打开 HardwareMonitor.xcodeproj，选 My Mac，⌘R 运行。或者命令行：

```bash
./build.sh
open build/Build/Products/Debug/HardwareMonitor.app
```

未签名的本地构建第一次运行要右键打开，或者去系统设置里允许。要分发的话得自己签名公证。

## 已知问题

- 风扇转速读不到，原因见上面
- 亮度走 DisplayServices 私有 API，系统大版本升级后如果符号变了会自动降级为不可用
- 只读硬件数据，不做任何写入，风扇控制、亮度调节这些都没做

## 环境

macOS 14+ 都能跑。开发机是 macOS 27 beta + Apple M5。Intel 机器理论上也支持，SMC 那条备用路径在 Intel 上可以直接读温度和风扇。
